# Command Palette
This mod adds a <cg>command palette</c> to Geometry Dash.

## Usage
On PC, press <cy>Alt+Space</c> (You can change it later) to bring up the command palette.

On mobile, there should be a button in the main menu that looks like this:

![Command Palette Button](demiomad.command-palette/mobile-button-preview.png?width=32)

If you have that button, click it.
